## Usage Notes

- All methodology files in this wiki/section document set trace back to the CFI free
  resources listed above. Where CFI content is incorporated under fair use, the original
  article is cited and linked.
- The KSF Stock Market Analysis system uses the **CFI DCF 8-step process** as the
  baseline for sheet-based intrinsic valuation on stock detail pages.
- Valuation strategy documents should cross-reference this page whenever DCF, LBO, or
  M&A model content is presented.
